# uCoz Content Manager — example prompts

## Materials

```text
Опубликуй в блоге статью «Как выбрать ноутбук для учёбы»: 5–7 тысяч знаков, подзаголовки, список критериев, обложка 1200×630, meta title и description. Категория — «Технологии».
```

```text
Вот таблица на 15 новостей (заголовок, текст, дата). Добавь их в модуль новостей с датами из таблицы, обложки сгенерируй в одном стиле. Сначала покажи первые 5 для проверки.
```

```text
Создай 3 черновика статей в каталоге статей (на модерации), не публикуй.
```

```text
Перепиши анонсы всех материалов в категории 4 блога: сейчас они дублируют первый абзац. Остальные поля не трогай.
```

## Styles and humanizer

```text
Напиши обзор беспроводных наушников Sony WH-1000XM6 по моим заметкам (ниже). Вердикт сверху, плюсы и минусы, кому подойдёт. Без рекламного тона.
```

```text
Сделай анонс дня открытых дверей в нашей школе: 15 марта, 10:00–14:00, актовый зал, регистрация по ссылке. Официальный стиль.
```

```text
Вот 5 статей из раздела «Советы», они звучат как ChatGPT. Перепиши по-человечески: убери канцелярит и штампы, факты и ссылки не трогай, картинки оставь на местах.
```

```text
Оформи эту инструкцию (текст ниже) как пошаговую: шаги, что понадобится, типичные ошибки. Скриншоты вставь в нужные шаги с увеличением по клику.
```

```text
Подборка «10 мест для пикника в Казани»: по картинке на каждое место, порядок — по удалённости от центра.
```

## Categories

```text
Создай в каталоге статей категории «Гайды», «Обзоры», «Новости рынка» с описаниями и SEO. Доступ — как у существующих категорий.
```

```text
Проверь, видят ли гости все категории блога. Если какие-то закрыты — покажи, ничего не меняй.
```

## SEO and URLs

```text
Сделай SEO-аудит модуля «Статьи» без изменений: мета, слаги, H1, вывод мета в шаблонах, дубли.
```

```text
Заполни meta title и meta description для всех статей без них. Пакетами по 20, с таблицей до/после.
```

```text
Мета-описания не попадают на страницу — поправь шаблоны блога, чтобы выводились $SEO_TITLE$ и description.
```

```text
Задай ЧПУ (ownurl) для 10 самых важных статей. Проверь SEO-модуль и его настройки, после записи проверь 200/301.
```

## Images

```text
Сгенерируй обложки для всех материалов блога без обложки: один стиль, без текста на картинках, alt для каждой. Загрузи пачкой.
```

```text
Добавь к статье 12 ещё 3 иллюстрации в галерею, существующие картинки не теряй.
```

```text
Для категорий FAQ сделай квадратные изображения 800×800 в фирменных цветах сайта.
```

## Modules and settings

```text
Установи модуль «Блог», убери демо-контент (после моего подтверждения), включи анонсы и обложки, 12 записей на страницу.
```

```text
Включи вывод даты добавления и закрепление материалов в каталоге статей. Сначала покажи dry run.
```

```text
Настрой доску объявлений: типы «Продам / Куплю / Отдам даром / Услуги», срок размещения по умолчанию 30 дней.
```
